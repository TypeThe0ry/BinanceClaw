# 常见问题

**为什么暂停了？**
暂停有三种原因：BTC 7 日跌幅超过阈值、连续出现行情异常、你手动暂停。原因会显示在顶部状态旁边，Telegram 里也会推送。确认没问题后，点 `恢复` 或发 `/resume`。

**为什么 AI 想买但没买？**
在 `AI` 页点开那一轮，「风控逐条检查」里写着被截断或拒绝的原因。

**批准了却没执行？**
批准后会用最新数据重新检查一遍风控。没执行的原因会写在审批记录里，常见的是今日笔数已达上限、已经暂停、稳定币不足。

**怎么重置模拟盘？**
在设置里切到模拟盘，点 `重置模拟盘`。

**开启实盘的按钮是灰的？**
要么还没输入确认短语，要么 Key 权限没通过检查。见 [模拟盘与实盘](live-mode.md)。

**模型调用失败？**
在设置里点 `连通测试`，或者运行 `binanceclaw doctor`。Claude 订阅需要已登录，或者已配置 token。

**怎么看日志？**
运行 `docker logs binanceclaw`。日志里所有像密钥的字符串都会被打码。
