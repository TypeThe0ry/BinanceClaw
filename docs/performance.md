# 绩效与回测

导航 **绩效** 有两个标签：**绩效** 看账户过去的真实表现，**回测** 用历史行情检验 AI 的决策。

## 绩效

按 7日 / 30天 / 90天 / 一年 / 全部 查看当前模式（模拟盘或实盘）的账户表现：

| 板块 | 内容 |
|---|---|
| 账户 | 收益率、同期 BTC 涨跌、年化收益、最大回撤与最长回撤期、夏普 / 索提诺 / 卡玛比率、年化波动，以及回撤曲线 |
| 已平仓交易 | 胜率、盈亏比（总盈利 ÷ 总亏损）、平均盈利 / 亏损、每笔期望、最大单笔盈亏、最长连胜 / 连亏，可分现货 / 合约查看 |
| 按币种 | 每个币的平仓笔数、胜率和盈亏 |

- 现货按平均成本法，每笔减仓卖出算一笔平仓；合约按已平仓仓位。
- 不足两周的历史按小时收益计算，满 30 天才显示年化收益和卡玛比率。
- 估值包含充值和提现，期间有资金进出时收益率和回撤会受影响。

**AI 也在看**：每轮决策的输入里带着近 30 天的这些数字（`performance_30d`）。回撤接近或超过 10%、连亏 3 次以上、或盈亏比低于 1 时，AI 会主动降低仓位和交易频率；明显跑输 BTC 时会在总结里反思配置思路。

## 回测实验室

在 **绩效 › 回测** 把历史 K 线逐轮回放给**同一套决策提示词、同一个模型和同一套风控**，看 AI 在过去的行情里会怎么做。

### 设置

| 项 | 范围 | 默认 |
|---|---|---|
| 币种 | 1–8 个 | — |
| 日期区间 | 最晚到昨天 | — |
| 决策间隔 | 4 小时 / 12 小时 / 1 天 | 1 天 |
| 初始资金 | $100 – $10,000,000 | $10,000 |
| 手续费 / 滑点 | 0–1% / 0–2% | 0.1% / 0.05% |
| 需要审批的交易 | 当作免审批执行 / 跳过 | 执行 |
| 卖出 | 跟随当前设置 / 允许 / 禁止 | 跟随当前设置 |
| 模型 | 任意模型 | 实盘决策用的模型 |

每轮调用一次模型，一次最多 400 轮；开始前会显示调用次数并要你确认。同一时间只运行一个回测。

### 怎么避免"作弊"

- **无未来数据**：每一轮只能看到那一刻已经收盘的 K 线；当天的日线由已收盘的 4 小时 K 线拼成。
- **不含日期**：提示词和实盘相同，但不带日历日期，减少模型凭记忆"预知"后来的行情。
- **同一套风控**：单笔 / 每日上限、稳定币下限、BTC 大跌暂停等都按你当前的设置执行。合约、理财和 AI 提问不参与回测。
- **真实成本**：按决策时的价格成交，扣手续费和滑点。
- 连续 3 轮模型出错或输出不合规时，回测自动停止。

### 结果

- 权益曲线，对比**持有 BTC** 和**等权持有所选币种**；
- 收益率、最大回撤、夏普等风险指标，已平仓交易的胜率和盈亏比；
- 模型调用次数与 token 用量；
- 交易记录和每一轮的决策轨迹（AI 的总结、动作和风控结果）。

运行中可以随时停止；服务重启会中断正在运行的回测。

> **回测 + 竞技场**：[模型竞技场](arena.md) 让几个模型在**实时**行情里同场比赛，回测则在**历史**行情里检验单个模型。先用竞技场挑出表现好的模型，再用不同市况（单边上涨、暴跌、震荡）的区间回测它，比只看一段收益更可靠。

回测只说明模型在过去行情里的表现，不代表未来收益。
