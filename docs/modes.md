# 模式一览

BinanceClaw 的行为由几组相互独立的开关决定。下表是全部模式、默认值和它们改变了什么，细节见每行链接的文档。

| 维度 | 可选模式 | 默认 | 在哪改 |
|---|---|---|---|
| [交易模式](#交易模式模拟盘--实盘) | 模拟盘 · 实盘 | 模拟盘 | 设置 → 交易模式 |
| [资产分配](#资产分配手动--ai-自主) | 手动分配（可选自动再平衡）· AI 自主分配（全部 / 白名单 / 黑名单） | 手动分配 + 自动再平衡 | 配置 → 资产与分配 |
| [决策时机](#决策时机ai-自主实时--固定间隔) | AI 自主实时 · 固定间隔 | AI 自主实时 | 设置 → 节奏 |
| [交易风格](#交易风格短线--中期--长期) | 短线 · 中期 · 长期 | 中期 | 配置 → 交易风格与观点 |
| [风险预设](#风险预设保守--均衡--积极) | 保守 · 均衡 · 积极 · 自定义 | 均衡 | 配置 → 风险预设 |
| [审批](#审批正常审批--免审批) | 正常审批 · 免审批（按时段 / 一直开启） | 正常审批 | 配置 → 免审批 |
| [AI 提问](#ai-提问) | 开 / 关；超时「不操作」或「按 AI 推荐执行」 | 开，超时不操作 | 配置 → AI 提问 |
| [交易品种](#交易品种现货--合约--理财) | 现货（始终）· 合约（可选）· 理财（可选） | 现货 + 理财 | 配置 → 合约；设置 → 理财 |
| [决策方式](#决策方式单模型--多空辩论) | 单模型决策 · 多空辩论（1–3 轮） | 单模型 | 设置 → 多空辩论 |
| [模型](#模型主模型--备用模型--按任务分配) | 主模型 · 备用模型 · 按任务分配 | 按任务分配开启 | 设置 → AI 模型 |
| [通知](#通知即时--定时汇总--免打扰) | 即时 · 定时汇总；免打扰时段 | 即时 | 设置 → Telegram 推送 |
| [运行状态](#运行状态运行--暂停--紧急停止) | 运行 · 暂停 · 紧急停止 | 运行 | 顶部状态栏 / Telegram |

另有两个**沙盒**，不受上面任何模式影响、也永远不碰真实账户：[模型竞技场](arena.md) 和 [回测实验室](performance.md#回测实验室)。

> **所有模式共用同一条底线**：无论怎么组合，模型都只输出 JSON 计划，每一笔都要经过同一个代码风控引擎。模式只改变「什么时候决策、交易什么、谁来批准」，不会放宽任何硬限制。

## 交易模式：模拟盘 / 实盘

| | 模拟盘 | 实盘 |
|---|---|---|
| 行情 | 币安真实行情 | 币安真实行情 |
| 资金 | 虚拟资金，默认 10,000 USDT，可重置 | 你的币安账户 |
| 成交 | 买一卖一价 + 滑点，手续费 0.1%，不调用下单接口 | 真实下单 |
| 决策、风控、审批、通知 | 与实盘完全相同 | — |
| 开启条件 | 无 | 输入确认短语，并通过 API Key 权限检查（提现必须关闭、必须设 IP 白名单） |

切换模式会作废所有待审批。模拟盘和实盘的估值、绩效分开记录。详见 [模拟盘与实盘](live-mode.md)。

## 资产分配：手动 / AI 自主

| | 手动分配 | AI 自主分配 |
|---|---|---|
| 谁定比例 | 你在「目标配置」里设每个资产的比例和区间 | AI 自己决定配置哪些资产、各占多少 |
| 可交易资产 | 目标配置里的资产 | 全部资产（默认）/ 白名单 / 黑名单 |
| 代码强制的上限 | 每个类别的区间上限 | 无单币上限，集中度由 AI 判断 |
| 自动再平衡 | 可选：偏离目标超过阈值（默认 5 个百分点）时自动下单调回 | — |

- **全部资产**：币安现货上所有有 USDT 交易对的资产（含代币化股票），AI 每轮从全市场概览里挑选关注的资产。
- **白名单**：只交易你选中的资产，最多 30 个。
- **黑名单**：和全部资产一样，但不买入黑名单里的资产。
- 范围外的已有持仓仍归 AI 管理，但**只卖不买**。

两种方式下，稳定币下限、单笔和每日额度、投入预算、审批规则都照常生效。详见 [资金管理与资产分配](capital-and-allocation.md)。

## 决策时机：AI 自主实时 / 固定间隔

| | AI 自主实时 | 固定间隔 |
|---|---|---|
| 下一轮什么时候 | AI 每轮自己定 `next_check_minutes` | 每隔「决策间隔」一轮 |
| 提前唤醒 | 价格波动超过阈值、触及关键价位或提醒、合约止损止盈 / 强平、成交、余额变化 | 无 |
| 边界 | 最短间隔 5 分钟、最长 240 分钟、每天最多 48 次调用（可改） | 决策间隔 |

两种方式下，你都可以随时手动跑一轮；改完影响决策的设置后，也会问你要不要立即重跑。详见 [什么时候决策](decisions-and-risk.md#什么时候决策)。

## 交易风格：短线 / 中期 / 长期

| | 短线 | 中期 | 长期 |
|---|---|---|---|
| 持仓周期 | 数小时到数天 | 数天到数周 | 数月以上 |
| 关注 | 1h / 4h 动量、量能、关键价位 | 日线趋势、支撑阻力 | 配置与长期趋势 |
| 自主模式复查间隔 | 5–60 分钟 | 跟随「节奏」设置 | 2–24 小时 |
| 默认波动唤醒 | 1% | 2% | 5% |

风格还可以配合**个人观点**（整体和单币五档看多 / 看空，加一段文字），作为 AI 的参考而不是命令。详见 [交易风格与个人观点](decisions-and-risk.md#交易风格与个人观点)。

## 风险预设：保守 / 均衡 / 积极

一键套用一组风控参数和决策频率：单笔上限、自动执行额度、每日笔数与金额、稳定币下限、BTC 暂停线。之后手动改任何一项，预设自动变成「自定义」。详见 [风险预设](risk-presets.md)。

## 审批：正常审批 / 免审批

| | 正常审批 | 免审批 · 按时段 | 免审批 · 一直开启 |
|---|---|---|---|
| 超过自动执行额度的交易 | 等你在网页或 Telegram 批准 | 时段内直接执行，时段外等你批准 | 直接执行 |
| 卖出、合约开仓 | 等你批准 | 需另外勾选才免审批 | 需另外勾选才免审批 |
| 硬限制 | 全部生效 | 全部生效 | 全部生效 |

免审批只跳过「等你批准」这一步，单笔上限、每日额度、稳定币下限、预算、合约止损等照常截断或拒绝。Telegram：`/sleep 23:30-07:30`、`/sleep on`、`/sleep off`。详见 [审批](approvals.md#免审批)。

## AI 提问

遇到高风险或取决于你偏好的决策时，AI 先在网页和 Telegram 上给你 2–4 个选项，回答后立即按回答决策。超时未回答时可以选：

- **不操作**（默认）：这件事维持现状；
- **按 AI 推荐执行**：采用 AI 标出的推荐选项，照常经过风控和审批。

详见 [AI 提问](approvals.md#ai-提问)。

## 交易品种：现货 / 合约 / 理财

| 品种 | 默认 | 说明 |
|---|---|---|
| 现货 | 始终开启 | 全市场现货，含代币化股票 |
| 合约 | 关闭 | USDⓈ-M 永续，逐仓、杠杆上限、强制交易所止损、单笔亏损上限；开仓默认要审批，可开启「小额自动开仓」。详见 [合约](futures.md) |
| 理财 | 开启 | 闲置资产自动申购活期，买卖前自动赎回；可申购全部有活期产品的资产，或只申购选中的稳定币。详见 [理财](earn.md) |

## 决策方式：单模型 / 多空辩论

| | 单模型 | 多空辩论 |
|---|---|---|
| 流程 | 决策模型直接写计划 | 多头、空头、风控三个角色先辩论 1–3 轮，再由决策模型权衡后写计划 |
| 每轮模型调用 | 1 次 | 1 + 3 × 轮数 次（同一轮并行） |
| 模型 | 按任务分配 | 每个角色可选不同提供方和模型 |
| 风控 | 相同 | 相同，辩论不放宽任何限制 |

详见 [多空辩论](debate.md)。

## 模型：主模型 / 备用模型 / 按任务分配

- **主模型**：Claude 订阅、OpenAI、OpenAI 兼容接口或 Anthropic API。
- **备用模型**：主模型调用失败时自动改用。
- **按任务分配**（默认开启）：投资决策、配置提案、对话、日报、辩论等任务分别用大模型或小模型；关闭后所有调用都用主模型。

详见 [模型](models.md)。

## 通知：即时 / 定时汇总 / 免打扰

- **即时**：随时推送到 Telegram。
- **定时汇总**：把可静音的消息攒起来，每 N 分钟合成一条。
- **免打扰**：时段内的可静音消息在结束时合成一条发送。

审批请求、AI 提问和重大风险提醒（止损触发、强平、风控暂停）始终立即推送。详见 [Telegram](telegram.md)。

## 运行状态：运行 / 暂停 / 紧急停止

| 状态 | 怎么进入 | 效果 |
|---|---|---|
| 运行 | 默认，或点 `恢复` / `/resume` | 正常决策和执行 |
| 暂停 | 手动暂停，或 BTC 7 日跌幅超过阈值、连续行情异常时自动暂停 | 不调用模型、不开新仓；合约止损一直在交易所生效，平仓和收紧止损照常可用 |
| 紧急停止 | `■ 紧急停止` / `/kill` | 暂停自动执行，作废所有待审批和待回答的 AI 提问 |

## 推荐组合

| 场景 | 组合 |
|---|---|
| 刚上手，先观察 | 模拟盘 · 手动分配 · AI 自主实时 · 保守预设 · 正常审批 |
| 选模型 | 模拟盘 · 开竞技场让几个模型同场比赛，再用回测检验胜出的模型 |
| 省心长期持有 | 实盘 · 手动分配 + 自动再平衡 · 长期风格 · 均衡预设 · 理财开启 |
| 交给 AI 主动管理 | 实盘 · AI 自主分配（白名单起步）· 中期风格 · 多空辩论 · 夜间免审批 |
