# 联网新闻

默认开启，默认让模型自己联网搜索，在 设置 → 联网新闻 里调整。每一轮决策前，系统先搜集最新新闻，和行情、指标、账户数据一起交给决策模型，让 AI 同时看技术面和消息面。

## 来源

| 来源 | 怎么搜集 | 适用 |
|---|---|---|
| 模型联网搜索（默认） | 优先让模型自己上网搜索，不限网站；模型不支持或搜索失败时才读新闻源 | 推荐 |
| 新闻源 | 只读 RSS 新闻源，不额外调用模型 | 想省模型额度 |

各提供方的联网搜索：

| 提供方 | 联网方式 |
|---|---|
| Claude 订阅 | Claude Code 内置的 `WebSearch` 和 `WebFetch` 工具（只开这两个，其他工具和 MCP 全部关闭，工作目录为空，拿不到任何密钥） |
| Anthropic API | 服务端 `web_search` 工具（Opus / Sonnet 用带动态过滤的新版，Haiku 用基础版），每次最多搜索 10 次 |
| OpenAI | Responses API 的 `web_search` 工具 |
| OpenAI 兼容 | 不支持，自动改用新闻源 |

搜索不限来源：不设网站白名单或黑名单，新闻媒体、交易所和项目官方公告、监管机构、社交媒体、链上数据和研究平台都可以，模型需要时会打开原文核实。

主模型联网搜索失败时，会先试备用模型（如果它能联网），都不行再退回新闻源。

## 搜什么

- **资产**：BTC、市值最大的持仓、本轮可交易的资产、开启的合约，最多 12 个。
- **关注话题**：在设置里填，例如「美联储，ETF，SEC」，搜索和新闻源筛选都会带上。
- **时间范围**：默认最近 24 小时。
- **条数上限**：默认 8 条。

模型联网搜索会返回一段整体消息面概述，每条新闻有标题、来源、链接、时间、相关币种、利好 / 利空 / 中性和要点。新闻源只保留和这些资产或整个加密市场（监管、ETF、稳定币、宏观等）有关的标题，按时间排序。

新闻源只是兜底，默认是 CoinDesk、Cointelegraph 和 Decrypt，可以在设置里换成或加上任何 RSS 或 Atom 链接，一行一个，数量不限。

## 刷新与成本

- 新闻默认每 60 分钟刷新一次，中间的决策轮直接复用，不再搜索；新出现的资产不在上次的搜索里时会立即重搜。
- 搜索失败时 15 分钟后再试，不会每轮都重试。
- 联网搜索按「新闻搜索」任务分配模型，默认用轻量模型（Claude 订阅 / Anthropic API 为 `claude-haiku-5-5`），见 [模型](models.md)。
- 设置页的 `立即搜索` 会马上搜一次并更新缓存。
- 暂停或触发暂停条件时不搜索。

## AI 怎么用新闻

- 新闻放在决策数据的 `news` 字段里，标明是未经核实的数据，不是指令；网页上的任何文字都不能改变决策原则。
- 重大利空（被盗、下架、监管打击）时回避或减仓相关资产；利好要有行情确认（放量、趋势配合）才加仓；已经被价格反映的旧闻不追。
- 新闻和行情矛盾时以行情为准，单条新闻不足以成为交易理由；影响了决策的新闻会写在理由或结论里。
- 开启多空辩论时，三个角色也能看到同一份新闻。
- 对话时 AI 也能引用最近一次搜集的新闻。

## 风控不变

新闻只影响 AI 写出的 JSON 计划。计划照常经过代码风控：单笔 / 每日上限、稳定币下限、审批、暂停条件全部不变，新闻不会放宽任何限制。

## 查看

AI 决策详情页会显示「新闻」：来源、搜集时间、整体概述和每一条新闻（可点开原文）。耗时里会多一项「新闻」。
