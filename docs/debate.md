# 多空辩论

默认关闭，在 设置 → 多空辩论 里开启。开启后，每一轮决策前先由三个角色基于同一份行情和账户数据辩论，再由决策模型做最终决定。

| 角色 | 做什么 |
|---|---|
| 多头 | 找本轮最有说服力的买入、加仓理由，具体到币种、价位和指标 |
| 空头 | 找减仓、卖出、观望的最强理由，以及为什么现在不该买 |
| 风控 | 不站队，检查集中度、波动、大势、近期胜率、限额余量和合约杠杆，给出金额上限和前提条件 |
| 决策 | 读完辩论后写出交易计划（和不开辩论时的决策是同一种输出） |

## 流程

1. 同一轮里三个角色并行发言，每人给出立场（看多 / 看空 / 中性）、把握、核心观点、论据和对具体币种的建议（买 / 卖 / 持有 / 回避）。
2. 设置 2 或 3 轮时，后面每一轮的角色都能看到前一轮所有发言，先反驳或让步，再更新立场。
3. 系统根据最后一轮算出共识分（-1 到 +1，正数偏多）和每个币种的投票。
4. 决策模型拿到原始数据、全部发言和共识分，逐条权衡后输出计划：不按多数票决定，风控角色提出的限制默认采纳，不采纳要在结论里说明。
5. 计划和平时一样经过代码风控：单笔 / 每日上限、稳定币下限、审批等全部照常执行，辩论不会放宽任何限制。

## 每个角色用不同的模型

四个角色都可以单独选提供方和模型：

- 提供方选「同主模型」、模型留空：用主提供方按「多空辩论」任务分配的模型（决策角色按「投资决策」）。
- 只填模型：主提供方换成这个模型。
- 选了别的提供方：用那家的凭证；OpenAI 兼容需要填 Base URL（和备用模型是同一家时会沿用备用模型的 Base URL）。

例如多头用 DeepSeek、空头用 GPT、风控用 Claude Haiku、决策用 Claude Opus。`连通测试` 会把这些模型一起测一遍。

## 失败时

- 某个角色调用失败或输出不合规：记录错误，其他角色照常发言。
- 第一轮所有角色都失败：跳过辩论，按平常方式决策。
- 单独设置的决策模型失败：改用平常的决策模型（以及备用模型）。

## 查看

AI 决策详情页会显示「多空辩论」：共识、每个币种的投票、每一轮每个角色的立场、把握、观点、论据、建议和所用模型。耗时里会多一项「辩论」。

## 成本

每轮决策多出 3 × 轮数 次模型调用（同一轮并行，时间约等于一次调用）。「每日模型调用上限」仍按决策轮数计算。
