# 模拟盘与实盘

## 模拟盘

- 行情是真实的，资金是虚拟的，默认 10,000 USDT，可以在设置里重置。
- 按买一卖一价加滑点成交，手续费 0.1%。
- 决策、风控、审批、通知的流程和实盘**完全一样**。
- 不会调用任何下单接口。

## 实盘准入

开启实盘时需要输入确认短语 `我确认开启实盘`，同时会读取币安 API Key 的权限，逐项检查：

| 权限 | 要求 | 能否豁免 |
|---|---|---|
| 读取 | 开启 | 否 |
| 现货交易 | 开启 | 否 |
| IP 白名单 | 开启 | 否 |
| 提现 | 关闭 | **否** |
| 合约、万向划转 | 关闭；**开启合约功能后改为必须开启** | 可以，需要在设置里逐项勾选「允许保留」 |
| 杠杆借贷、内部划转、期权、统一账户 | 关闭 | 可以，需要在设置里逐项勾选「允许保留」 |

BinanceClaw 只在开启[合约](futures.md)后才用合约接口，以及现货和 U 本位合约账户之间的万向划转（只有这两个方向）。代码里没有杠杆借贷、提现接口。豁免意味着：Key 如果泄露，这些权限会扩大可能的损失。

实盘下开启合约时，会先检查 Key 是否有合约和万向划转权限，没有就不让开启。

## 切回模拟盘

随时可以切回，不需要任何检查。实盘持仓不受影响。
