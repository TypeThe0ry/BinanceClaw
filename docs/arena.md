# 模型竞技场

让多个模型各自管理一个**虚拟账户**，在同一时刻、同样的实时行情、同样的规则下比赛收益率，看哪个模型最会交易，再决定主账户用哪个。

## 永远不碰真实账户

- 竞技场不调用任何下单接口。成交只改动每个参赛模型自己的虚拟余额，和实盘账户、主模拟盘账本完全隔离，无论当前是模拟盘还是实盘。
- 行情、盘口来自币安公开数据，和主流程用的一样。
- 模型调用会消耗你的额度（API 费用或订阅用量），比赛频率在「规则」里控制。

## 公平性

- **同一快照**：每一轮只取一次行情和盘口，所有模型拿到完全相同的数据，并行决策。
- **同一规则**：只做现货、不加杠杆；单笔不低于 $10；买入后单个币种不超过总资产的「单币上限」；成交按本轮盘口价，另计滑点和手续费（与模拟盘设置相同）。
- **同一起点**：每个模型从相同的初始资金开始。中途加入的模型从加入时开始计算，「超额 BTC」按它自己的起点比较。

## 页面

导航 **竞技场**（手机在「更多」里）。

| 标签 | 内容 |
|---|---|
| 排行 | 收益率曲线（虚线是 BTC 持有基准）；排名表：总资产、收益率、超额 BTC、最大回撤、夏普、胜率（已平仓卖出中盈利的比例）、交易笔数、回合数和出错次数。点一行展开持仓、已实现盈亏、手续费、Token 用量和最近回合 |
| 回合 | 每一轮所有模型对同一份行情的决策并排对比：总结、把握、每笔动作和成交结果（被规则拦下的划线并注明原因） |
| 参赛与规则 | 添加 / 停用 / 移除模型；自动比赛开关、间隔、每日最多轮数、单币上限、初始资金、比赛币种 |

右上角：**立即比赛** 马上跑一轮；**重置** 开始新赛季（所有模型回到初始资金，成绩和回合记录清空）。

## 参赛模型

每个参赛者是「提供方 + 模型」的组合，最多 8 个，例如：

- Claude 订阅 · claude-opus-5-5
- Claude 订阅 · claude-haiku-5-5
- OpenAI · gpt-5.5
- OpenAI 兼容 · deepseek-chat（填 base_url）

API Key 沿用 [模型](models.md) 里配置的同一套环境变量（`OPENAI_API_KEY`、`OPENAI_COMPAT_API_KEY`、`ANTHROPIC_API_KEY`、Claude 订阅登录）；缺少凭据的模型显示「不可用」，那一轮记为出错，不影响其他模型。

## 排名指标

| 指标 | 含义 |
|---|---|
| 收益率 | 当前总资产 ÷ 初始资金 − 1，按最新价估值 |
| 超额 BTC | 收益率减去同期 BTC 涨跌幅；正数表示跑赢了「全仓买 BTC 拿着不动」 |
| 最大回撤 | 资产曲线从高点到低点的最大跌幅 |
| 夏普 | 年化夏普比率，和「绩效」页同一算法；历史太短时显示 — |
| 胜率 | 卖出时价格高于持仓均价（扣除手续费后）的比例，括号里是已平仓次数 |

资产曲线在每轮结束后和两轮之间每 15 分钟各记录一次。
