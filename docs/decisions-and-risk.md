# AI 决策与风控

## 一轮决策

1. 拉取行情（价格、7 日和 30 日涨跌、14 天日线收盘价）和账户余额。
2. 检查暂停条件。已经暂停，或者触发了暂停条件时，**不调用模型**，本轮跳过。
3. 把数据交给模型。模型只能返回一份 JSON 计划：摘要、行情观点、动作列表、信心。每个动作都必须写理由和"判断错了的信号"。
4. 解析失败、超时或模型报错时，**本轮不交易**，只发通知。
5. 风控引擎逐条检查动作，每个动作只会落到以下一种结果：
   - `自动执行`：不超过自动执行额度，并且今日自动执行总额还有剩余。
   - `待批准`：超过额度，等你确认。
   - `截断`：只放行允许的部分，再按上面两条处理。
   - `拒绝`：违反硬限制。
6. 全过程写入审计记录：输入、提示词、原始输出、风控结果、成交。

模型还可以给出最多 3 个**价格提醒**（通常就是它判断错了时的关键价位）。新一轮会替换它之前设的提醒；离现价超过 50%、或者设了就会立即触发的价位会被丢弃。提醒只做通知，不会自动交易。

主模型调用失败时，如果配置了**备用模型**，会自动改用备用模型，审计里会记下这一点。两个都失败时，本轮不交易。

决策调用时模型**没有任何工具**，能影响结果的只有这份 JSON，所以提示注入最多只能让它提出一个仍然要过风控的方案。

## 硬限制

| 限制 | 默认 | 说明 |
|---|---|---|
| 白名单 | 设置里选中的资产（USDT 计价） | 其他交易对一律拒绝，包括合约交易对 |
| AI 投入预算 | 不限 | 设置后，累计净投入不超过预算 |
| 锁定资产 | 无 | 锁定的数量对 AI 不可见、不可用 |
| 只买不卖 | 开 | 可以在设置里允许卖出，但卖出**永远**需要人工批准 |
| 单笔上限 | $800 | 超出部分截断 |
| 单笔自动执行上限 | $200 | 超过就进审批 |
| 每日自动执行总额 | $400 | 防止 AI 把大单拆成多笔小单来绕过审批 |
| 每日笔数 | 3 | 达到后当天不再买入 |
| 每日成交总额 | $2,400 | 超出部分截断 |
| 稳定币下限 | 15% | 买入后稳定币占比不得低于此值 |
| 类别区间上限 / 单币上限 | 见目标配置 / 70% | 按目标配置时限制类别上限，AI 自主分配时限制单币占比 |
| 每轮动作数 | 3 | 多余的拒绝 |
| BTC 7 日跌幅暂停 | 25% | 触发后暂停，需要手动恢复 |
| 行情异常暂停 | 连续 3 次 | 例如缺价格、K 线停更、价格偏离过大 |

每个数值都有代码写死的上下限（`config.py` 的 `HARD_BOUNDS`），设置页填超出范围时，会被收回到范围内。

## 执行前的最后检查

每一笔下单前，都会用**最新数据**把全部检查重跑一遍，自动执行和人工批准都一样。所以批准时，如果期间已经暂停、额度用完或者价格异常，订单不会执行。
