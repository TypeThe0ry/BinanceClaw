# Telegram

## 推送

| 事件 | 内容 |
|---|---|
| 待审批 | 4 小时 K 线图，黄色 ▲ 是待批准位置，附理由、判断错了的信号，以及「批准 / 拒绝」按钮。所有来源的审批（AI 决策、自动再平衡、合约）都会推送；发送失败会每 30 秒重发，直到送达或过期 |
| 目标配置提案 | 在网页上让 AI 生成的配置提案也会推到 Telegram，带「应用 / 放弃」按钮 |
| 自动执行 | K 线图，标出本次成交 |
| 自动再平衡成交 | 同上，可以单独关闭 |
| 理财申购 / 赎回 | 文字（默认关闭） |
| 审批结果 | 原消息更新为已批准、已拒绝、已过期或未执行 |
| 不操作 | 本轮结论 |
| 暂停 / 恢复 / 模式切换 / 告警 | 文字 |
| 日报 | 资产曲线图、配置对比图，加上 AI 点评 |
| 价格提醒触发 | K 线图上标出提醒价位，注明是你设置的还是 AI 设置的 |
| 告警 | 模型失败、行情异常、下单结果未知、超过 3 个周期没有成功决策 |

## 推送设置

在网页「设置 → Telegram 推送」或用 `/notify` 指令调整：

- **消息类型**：每类消息（自动成交、再平衡、不操作的决策、理财、日报、价格提醒、系统提醒）都可以单独开关。
- **推送频率**：「即时」随时推送；「定时汇总」把消息攒起来，每 N 分钟（5–1440）合成一条发送，最早那条最多等 N 分钟。
- **免打扰**：设定时间段（按设置里的时区，可以跨午夜，例如 23:00–08:00），期间的消息在结束时合成一条发送。

**审批请求、AI 提问和重大风险提醒**（止损触发、强平、风控暂停、下单结果未知）不能关闭，也不受汇总和免打扰影响，始终立即推送。汇总消息只有文字，不带图表。

## 指令

| 指令 | 作用 |
|---|---|
| `/status` | 资产、配置、今日额度、状态 |
| `/run` | 立即跑一轮决策 |
| `/pause` · `/resume` | 暂停或恢复自动执行 |
| `/kill` | 紧急停止并作废待审批 |
| `/pending` | 重新推送所有待审批 |
| `/log` | 最近 5 轮决策 |
| `/report` | 立即生成日报 |
| `/chart BTC 4h` | K 线图，币种和周期（1h、4h、1d）都可以省略 |
| `/pnl` | 成本价与盈亏，以及「全买 BTC」的对比 |
| `/positions` | 合约持仓：方向、杠杆、浮盈、止损止盈 |
| `/flat yes` | 平掉 BinanceClaw 开的全部合约仓位 |
| `/alert BTC < 76000 备注` | 设置价格提醒（`>` 表示涨破） |
| `/alerts` · `/unalert 编号` | 查看或删除提醒 |
| `/preset 名称` | 套用风险预设 |
| `/budget 3000` · `/budget off` | 设置或取消 AI 投入预算 |
| `/lock BTC 0.5` · `/lock BTC 0` | 锁定或解除锁定资产 |
| `/assets ai` · `/assets manual` · `/assets all\|whitelist\|blacklist` · `/assets BTC,ETH` · `/assets block DOGE` | 切换 AI 自主 / 手动分配、AI 可交易范围、白名单和黑名单 |
| `/alloc 加 10% TON，从 BTC 里减` · `/alloc` | 让 AI 修改或生成目标配置，点按钮应用或放弃 |
| `/notify` | 查看推送设置 |
| `/notify instant` · `/notify digest 60` | 即时推送，或每 60 分钟汇总一次 |
| `/notify quiet 23:00-08:00` · `/notify quiet off` | 设置或关闭免打扰 |
| `/notify off earn,决策` · `/notify on 理财` | 关闭或打开某类消息（类型名见 `/notify`） |
| `/notify flush` | 立即发送攒着的汇总 |
| `/new` | 开始新的对话 |

`/preset`、`/budget`、`/lock` 和 `/assets ai|targets` 改的是[危险设置](decisions-and-risk.md#危险设置要二次确认)，机器人会先列出改动，点「确认修改」才生效。

这些设置生效后，如果会影响 AI 的决策，机器人会附上「🧠 立即重跑」按钮，点了就按新设置马上跑一轮手动决策（按钮 10 分钟内有效）。

其他文字会直接发给当前模型，它只能读、不能下单。只有绑定的那个账号能使用这个机器人。
