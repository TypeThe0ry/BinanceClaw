# 合约（USDⓈ-M 永续）

合约默认关闭，需要在「设置 → 合约」手动开启。开启后，AI 每轮除了现货动作，还可以提出合约动作；合约动作同样由代码风控逐条检查。

## 能做什么

| 动作 | 含义 | 执行方式 |
|---|---|---|
| `OPEN_LONG` / `OPEN_SHORT` | 开多 / 开空，必须带止损 | **默认需要你批准**；开启「小额自动开仓」后，保证金不超过设定值的才自动执行 |
| `CLOSE` | 全部平仓 | 自动执行，暂停期间也可以 |
| `REDUCE` | 按比例减仓 | 自动执行，暂停期间也可以 |
| `SET_STOP` | 调整止损 | 只能**收紧**（多单上移、空单下移），自动执行；放宽一律拒绝 |

同一个合约已有持仓时，不能再开新仓：不加仓、不反手。要换方向，先平仓。

## 硬限制

| 限制 | 默认 | 说明 |
|---|---|---|
| 可交易合约 | BTC、ETH | 只能交易币安正在交易的 USDT 本位永续合约，可以搜索添加 |
| 最大杠杆 | 3x | 超过的会被下调到上限，不会拒绝 |
| 单仓保证金上限 | $200 | 超过的会被截断 |
| 总保证金上限 | $500 | 包括还在对账中的仓位 |
| 单笔止损最大亏损 | $30 | 保证金 × 杠杆 ×（止损距离 + 双边手续费）超过它，就缩小仓位 |
| 止损最远距离 | 8% | 止损离标记价太远（或近于 0.2%）会被拒绝 |
| 强平保护 | — | 止损必须在估算强平距离的 80% 以内，否则拒绝（提示降低杠杆或收紧止损） |
| 每日开仓次数 | 3 | — |
| 允许做空 | 是 | 可以关掉 |

保证金还要满足现货的「稳定币下限」和「AI 投入预算」。合约仓位的权益（保证金 + 浮动盈亏）在资产页显示为「合约权益」，计入总资产和稳定币占比。

触发暂停条件（BTC 大跌、行情异常、手动暂停、紧急停止）时**不开新仓**，但已有仓位的止损一直在交易所生效，平仓和收紧止损照常可用。紧急停止不会自动平仓，要全部平仓请用合约页的「全部平仓」或 Telegram `/flat yes`。

## 止损怎么保证

- 实盘每次开仓成交后，立刻在币安挂一张 `STOP_MARKET`（按标记价触发，`closePosition`）止损单，通过币安的条件单（Algo Order）接口。
- 止损单挂失败，**立即平掉这个仓位**，并推送通知。持仓不会出现没有止损的时刻（除了成交到挂单之间的几百毫秒）。
- 每 10 秒和交易所对账一次：止损单不见了就重新挂；重挂也失败就平仓。仓位在交易所被止损、止盈、强平或你手动平掉，会自动记录并推送。
- 只撤 BinanceClaw 自己挂的条件单，不碰你在币安上自己下的单。某个合约上已有不是 BinanceClaw 开的仓位时，BinanceClaw 不在那个合约上开仓。

## 资金怎么走

- 开仓前，把需要的保证金从现货划到 U 本位合约账户（`MAIN_UMFUTURE`）。
- BinanceClaw 没有任何持仓时，把合约账户里可用的 USDT 划回现货（`UMFUTURE_MAIN`）。
- 代码里只有这两种划转，没有提现，也没有其他划转方向。

## 账户设置

- 一律使用**逐仓**，开仓前会把该合约设为逐仓并设置杠杆。
- 单向持仓和双向持仓（Hedge Mode）都支持；BinanceClaw 不会修改你的持仓模式。

## 模拟盘

- 按币安真实标记价成交（加滑点），手续费按 0.05% 计。
- 保证金从模拟盘的 USDT 扣除，平仓后连同盈亏返还；逐仓亏损最多亏掉该仓位的保证金。
- 每 10 秒按标记价检查止损、止盈和估算强平价。
- 不计资金费率。

## 实盘权限

开启合约后，实盘准入会要求 API Key 打开「合约」和「万向划转」两项权限（只用来做现货和合约账户之间的划转）。提现权限依然必须关闭。

## 风险

杠杆会放大亏损。止损单在行情剧烈波动或流动性很差时可能以明显差于止损价的价格成交；极端行情下仍可能被强平。合约是可选的辅助工具，不建议让它成为主要仓位。
